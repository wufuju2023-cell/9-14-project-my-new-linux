# 02 — 里程碑与门（Milestones & Gates）

> 所有开发以本表验收；每模块自己的门见 `modules/M*/README.md`。
> 环境终点：AMD MI300X 192GB；本地阶段只写代码与文档，零部署。

## M-0 接口冻结（前置）
- [ ] 8 模块 README（数学+伪代码）+ 代码骨架齐备；
- [ ] `9-14-code/shared/schemas.py` 为唯一 schema 源；
- [ ] 每个模块含 `AGENT.md`（引用行号/依赖/上云环境）。
- **门**：任意模块可在缺失其它模块实现时通过"接口桩"运行单测。

## M-1 单专家最小闭环（LoRA 路线）
- [ ] M1+M2：3 题（IMO2019Q1/Pell×2）工具链 MCTS 跑通（本地 Lean 4.28 验证）；
- [ ] M4：服务复用（REAL-Prover + full-v3 头）；smoke 值 1.786/1.962/3.216；
- [ ] M5：learn/v1 一次 TTT 更新回执；
- **门**：3 题全绿 + 更新后版本号递增且被后续消费。

## M-2 多专家（M3）
- [ ] 2-4 个专家（不同领域 adapter）注册+路由；
- [ ] 联合奖励一次结算（含互补项）；
- **门**：路由正确率 ≥95%（离线集合）；联合奖励不劣于单专家基线。

## M-3 课程与 2k 数据（M7）
- [ ] R1 受限变体 ≥300 题过验证门（通过率>90%）；
- [ ] R2 agent 生成器 ≥100 题（通过率>25%，类平衡偏差<30%）；
- **门**：课程由易到难分层成功树产出率报告。

## M-4 QLoRA 对照研究（M6）
- [ ] ROCm 下 bitsandbytes/QLoRA 可用性结论；
- [ ] LoRA vs QLoRA 四维对照（显存/速度/精度/适配性）；
- **门**：给出"用/不用 QLoRA"的**书面裁定**（含数据表）。

## M-5 RL 与多样性（M5+M8）
- [ ] 100-200 题课程跑 1-2 轮 MCTS 蒸馏主更新（GRPO 暂时禁用）；
- [ ] pass@1 与 pass@k 同报（防塌缩门：pass@k 下降>30% 触发回退）；
- **门**：奖励提升且 pass@k 不塌（或给出为何可接受的证据）。

## M-6 长时程与发布
- [ ] 8h 级运行：0 门违反、COMPLETE 全绿、可回放；
- [ ] snapshot/release/retire 回执链完整。
- **门**：任何 release 附 source/base/adapter/head identity。
